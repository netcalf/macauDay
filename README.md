# Outbound Statistics Generator

A Python utility for extracting **outbound/inbound travel records** from PDF files and generating **academic-year based stay-day statistics** in both Excel and Markdown formats.

This tool is designed for scenarios where the source PDF contains records such as:

- `出境 2025-03-01`
- `入境 2025-03-02`

It converts paired `出境/入境` events into **stay dates**, then summarizes them by **academic year**.

---

## Features

- Extracts `出境` / `入境` events from PDF files
- Automatically normalizes reversed event order if needed
- Expands paired exit-entry records into **inclusive stay dates**
- Groups statistics by **academic year** (`09-01` to `08-31`)
- Outputs results to:
  - Excel (`.xlsx`)
  - Markdown (`.md`)
- Includes a **total row** in the output
- Supports holiday filtering using the `holidays` library (Macau region, `MO`)
- Provides the following statistics for each academic year:
  - 境外停留总天数
  - 单日去重后天数
  - 去除假期后天数
  - 去除周末和假期后天数

---

## Output Columns

| Column | Description |
|--------|-------------|
| 学年 | Academic year span, e.g. `24-25学年 (2024-09-01~2025-08-31)` |
| 境外停留总天数 | Total stay days, counting all expanded days |
| 单日去重后天数 | Unique stay dates after deduplication |
| 去除假期后天数 | Unique stay dates excluding public holidays |
| 去除周末和假期后天数 | Unique stay dates excluding both weekends and public holidays |


## Example Output

### Real Example

The following is an actual sample generated by the script:

| 学年 | 境外停留总天数 | 单日去重后天数 | 去除假期后天数 | 去除周末和假期后天数 |
|------|----------------|----------------|----------------|----------------------|
| 23-24学年 (2023-09-01~2024-08-31) | 171 | 164 | 163 | 155 |
| 24-25学年 (2024-09-01~2025-08-31) | 61 | 58 | 57 | 52 |
| 25-26学年 (2025-09-01~2026-08-31) | 82 | 75 | 75 | 72 |
| **总计** | **314** | **297** | **295** | **279** |

### Meaning of the result

- `境外停留总天数`: total expanded stay days
- `单日去重后天数`: unique stay dates after deduplication
- `去除假期后天数`: unique stay dates excluding public holidays
- `去除周末和假期后天数`: unique stay dates excluding both weekends and public holidays

In this example, the final summarized result is:

- **314** raw stay days
- **297** deduplicated stay days
- **295** stay days excluding holidays
- **279** stay days excluding weekends and holidays
